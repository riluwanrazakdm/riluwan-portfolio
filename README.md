# Riluwan P Razak: portfolio (Next.js 14)
- `npm install && npm run dev`, then deploy via GitHub and Vercel.
- Videos: export each reel as MP4 (H.264, 720x1280, under 6 MB) to `public/videos/<reel-id>.mp4`, for example `DSULhQMiSSA.mp4`. They autoplay muted when scrolled into view. Without a file the tile links to Instagram.
- Content lives in `lib/markup.js`, motion in `lib/engine.js`, styles in `app/globals.css`.
